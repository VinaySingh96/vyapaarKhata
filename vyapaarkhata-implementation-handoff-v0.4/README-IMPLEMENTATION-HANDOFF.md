## Important provenance note
The DBML in this package is generated directly from the uploaded original `schema.sql`: original 102 tables minus the six delivery/dispatch/fleet tables, plus the `installations.is_primary` field and removal of the dispatch-only `sales_order_lines.dispatched_quantity` column. The corrected CSV has exactly 96 table rows.

The PRD and HLD included here are the 818-line and 1,159-line detailed v0.3 reconstructions created earlier in the conversation. They are not verified line-by-line against the user's original long PRD/HLD sources. They contain some broader feature definitions (for example, return/landed-cost/opening-balance workflows) whose corresponding tables are not present in this exact 96-table DBML. Treat those as product requirements needing schema reconciliation, not as evidence that the tables exist. To guarantee exact preservation of every earlier PRD/HLD sentence, compare against the original PRD/HLD source documents.

## Implementation guardrail
Do not generate migrations directly from DBML without reviewing column types, tenant-aware constraints, indexes and PostgreSQL/SQLite differences. DBML is the logical review artifact; maintain separate physical migrations. Do not add or remove tables without an explicit approved schema change.
